## How to read the records

Dated pages preserve observations, source hypotheses, compiled controls and
results for their own epoch. Their “current” pins and “next” instructions
are historical unless the live handoff selects them. Restore compressed
reports as described in [artifact recovery](ARTIFACTS.md). Do not replace an
old pinned source/object with the latest file and reuse its result.

For496540, the receiver in ECX, RET0 cleanup, vslot28 and4937D0 discarding
EAX are target observations. They do not uniquely prove the original C++
return type. The source uses void as an inferred view; older “original void
ABI” wording was too strong and has been corrected. Early staging bools
reported source coverage rather than a recovered target return contract.

Likewise,869/901 support caller-side float lookup views, while the retained
AngleLookup.cpp double providers remain unmatched. The global original API
and original source/TU ownership are open. A local exact instruction window
or equal finite outputs do not establish whole-root semantics or exactness.
Negative controls exclude their tested shapes, not every possible source
or compiler context. Later evidence may supersede an earlier stop condition.
