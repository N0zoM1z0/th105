## Observed target and source

Fresh Factory-native IDA metadata, entry, five mapped-byte samples and semantic
probes agree with the pinned Japanese1.06a executable. Raw PE independently
closes all33 instructions/88 bytes of409020 and219 instructions/696 bytes of
4094E0, including its remote lock-failure tail. There is no unreachable alignment
or indirect switch table in either body. DDS calls creation at40961B; the real
bitmap texture fallback409080 calls DDS at4090D8. Decompiler prototypes were
not adopted as artificial register conventions.

The helper tests backend capability byte+64 bit20 and expands the smaller
requested dimension to the larger when square textures are required. It holds
the real backend critical section while calling D3DXCreateTexture with usage0,
pool1, requested level count/format and the output pointer. HRESULT is returned
after unlocking. Ordinary static stdcall C++ in the real caller TU naturally
derives ECX width, EAX height, three stack arguments and RET12.

DDS source retains the four-argument stdcall boundary and FileReaderOwner.
It checks magic20534444, reads a real124-byte header, rejects caps2 bit200 and
accepts exactly DXT1 through DXT5. Mipmap count defaults to1 only when zero.
Width and height are copied to caller outputs only after successful upload.
The creation failure path prints the exact existing failed-newline literal.

Native flags8 selects the block-size calculation using floor division by4 and
a minimum of1 in each dimension, times8 for DXT1 or16 for other accepted DXT
formats. Otherwise flags80000 selects the header's linear size, or size0.
Each level locks, reads the selected byte count, unlocks the same level, and
quarters the count with a minimum of1. No modern ceil-rounding, read-result
validation, or extra release behavior is added. On a lock failure the original
returns8876086C without publishing/releasing the local texture; the source
preserves that behavior rather than silently repairing it.

The124-byte header's reserved words are actual disk-format fields, not frame
padding. Existing reader and D3D type definitions are unchanged. DdsTexture9
extends the existing verified18-slot texture interface with LockRect/UnlockRect
at4C/50; no fake slot is called. Original nominal type/TU spelling is unknown.
