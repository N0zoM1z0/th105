## Source and x87 decision

TH08's `src/ZunMath.hpp` uses inline assembly to emit `FSINCOS` for specific vector helpers. The complete TH105 Iku root contains no `FSINCOS` or `FRNDINT`, and these four cases contain ordinary x87 loads, arithmetic, stores, conversions and stack rounding boundaries. TH08's VC7 source is therefore a technique reference, not evidence of a TH105 assembly requirement. TH105's repository rules forbid assembly to force matching. Preserve the observed float/double widths and evaluation order in a truthful VC8 C++ hypothesis first; compare an actual configured unit before making any source-present or exact claim.
