## Why a separate source proof is needed

The original ordinary-COFF origin gate cannot describe helpers whose private
register/stack lowering is produced by actual LTCG. An initial read-only scan
of37 retained linked images found101 masked shape leads; those were neither
fresh provenance nor acceptance. Only the six pure standard-container bodies
above are promoted here, after independent current builds and full byte proof.
No other masked lead is inferred exact or excluded.

No C++ source, compiler profile, SDK header or existing match-unit declaration
is changed. Existing real network, package and input translation units generate
these original VC8 header functions. Standard C++ declarations remain ordinary;
no private ABI, copied instructions, assembly, synthetic wrapper or linker
barrier is introduced. Their decorated source identities establish template
families, not unique original game-side nominal type or translation-unit names.

## Fail-closed whole-body gate

The new vc8_linked_generated_anchor_file path is separate from the existing
ordinary-COFF evidence. Its schema has no adjustable mask, reduced coverage,
partial-match, alignment-tail or nonexact-root option. It accepts only the
reviewed vector _Ufill and tree _Lrotate/_Rrotate families, minimum24 bytes.
All accepted bytes are compared:100% coverage, zero masks and zero rewrites.

Every invocation performs a fresh normal configured CIL build using the pinned
compiler/linker/SDK/runtime, then the existing independent provenance checks and
complete exact replay of already accepted roots. The matched roots are:

- pointer fill: actual token release405200/167;
- byte fill: input update40A550/266;
- package rotations: package owner constructor41B8C0/163 and destructor41B980/228;
- network rotations: manager destructor413820/98 and constructor413780/145.

A unique MAP function must belong to that exact source CIL object. The entire
symbol-bounded body, excluding only ordinary post-function INT3 linker fill,
must equal the complete target candidate and its pinned hash. Both CFGs must
close; a truncated prefix, omitted trailing code, unresolved indirect tail,
call, absolute/segmented reference or PE relocation rejects the proof. The
normal canonicalizer must also be an identity with no call/data references.
Source PE relocation absence is not a claim that the fixed-base original has
a relocation directory. It has none.

The raw body is searched against all4027 candidates, including already matched
and excluded rows. Exactly the declared address must match. All six pass this
full-inventory uniqueness check. The four tree bodies each have28 decoded
instructions; pointer fill has15 and byte fill16. No target bytes are patched.
Twelve tests cover complete identity, uniqueness across accepted rows, schema/
threshold restrictions, source ownership, exact proof roots, relocation/data/
call rejection and omitted/trailing code. Existing validators are not weakened.
