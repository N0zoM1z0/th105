The new origin rule pins the body, CRT incoming edge, two exact outgoing

## Recovered complete behavior

- Create the named mutex using the target Shift-JIS title. Return one on
  ERROR_ALREADY_EXISTS. Preserve the target's early-return resource behavior.
- Obtain the module filename with capacity260; truncate after the final
  backslash and set the process directory. The target has no missing-slash guard.
- Compute window dimensions from three width metrics plus640, and four height
  metrics plus480. Publish all 48 WNDCLASSEXA bytes through ordinary fields.
- Use class `th105_106a`, icon name `IDI_ICON`, small-icon resource112, arrow
  cursor and BLACK_BRUSH. Format the target title as `%s`, then create the
  observed application window, show it with the incoming mode and update it.
- Construct the already exact 40-byte startup options. Supply HWND/HINSTANCE,
  a four-byte CSceneManager and a twelve-byte CFade. Their implicit ordinary
  constructors publish the target five-slot vtables without initializing
  CFade's color/timer scalars. Enable IME and flag27; keep graphics_flag25 false.
- Mount `th105b.dat`, then `th105a.dat`. Each failure closes the mutex and
  releases both callback allocations before returning zero. Mount `th105c.dat`
  afterwards and ignore its return value.
- Initialize singleton `702820`; run it on success, or show the target
  initialization-failure message on failure. Hide the window, call the already
  exact application shutdown, close the mutex, and return zero.

All Win32 imports were identified from PE descriptors/IAT cells, including
GetSystemMetrics at `6C0248`, ShowWindow at `6C021C`, and wsprintfA at
`6C01D8`. The main window procedure at `6657E0` is a separate 33-byte stdcall
forwarder to application dispatch `408690`. Its code pointer is a WinMain
field initializer, without source-present credit for the forwarder here.
The scene/fade tables at `6C74AC/6C74C4` and their RTTI type identities are
independently pinned. The entry-only C++ views do not claim original class/TU
spelling or a recovered full application layout.
