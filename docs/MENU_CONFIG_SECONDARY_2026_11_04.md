It remains nonexact against the native body/table; neither table bytes nor

A bounded x86 observer checks 42 native/source cases: five primary cases and
two out-of-range selectors, with six signed values covering negative, zero,
normal and above-range inputs. It checks secondary cursor state, binder call,
gauge call arguments and stack cleanup. The binder and sprite texture calls
are controlled mocks, and dimensions are fixed. All traces agree; a mutated
clamp is detected. This does not prove actual UI rendering, all input values,
exception behavior or whole-game execution.

main menu update in a fresh comparison. The menu constructor remains a
