## Narrow validation extensions

DDS ends with a reachable remote failure block jumping backward to the existing
return epilogue. The linked decoder now permits that terminal internal JMP only
when a RET exists and the entire instruction graph closes without escapes,
interior targets or unreachable bytes. No byte or edge is ignored. Negative
fixtures reject external/interior/unreachable/no-return and indirect cases.

The failed-newline literal is passed to printf by PUSH. An explicit
allow_pointer_push=true contract permits only the complete independently
verified readonly string at offset0. Interior pointers, implicit opt-in, arbitrary
MOV address uses, writes and excess reads remain rejected. Default literal
contracts still forbid pointer pushes.

Source-only caller proof now also admits an ordinary stdcall function with
complete cleanup EH and a real included caller source, alongside the previously
supported constructor. It requires static CRT/cookie provenance, the exact
reachable source/target call edge, source inclusion and bounded address roles.
It does not waive the callee's body, handler, funclet or metadata comparisons.
