## Ownership and full boundary

The CSelect primary RTTI table is 6C0BC4; its +8 render slot at 6C0BCC points
here. COL 6D78D0 points to type descriptor 6E6050, named .?AVCSelect@@. The
existing generic origin validator independently checks these pointers, the
entire native body hash, and direct begin/overlay/guide/finish call edges.
No generic ownership or comparison rule is relaxed.

Both native and source have 421 decoded instructions, 419 reachable. The only
unreachable instructions are LEA ESP,[ESP] at 420068 and NOP at 42006F, skipped
by EB08 at 420066 before a 16-byte loop entry. All eight bytes remain in the
comparison; the dedicated CFG audit permits only this exact reviewed span.
Both RET0 paths at 41FF18 and 4204D8 are covered. The apparent saved EBP/EDI
registers are not fabricated source parameters: this is bool thiscall render().

The source covers begin-frame failure, character boxes and portraits, random
character display, active effects, player cursors, names/previews, seven stage

## Isolated observer checks

The public audit emulates only this bounded body with a controlled object and
records external call receivers and argument bit patterns. Every external call
is intercepted; unobserved helper execution is rejected. No graphics, game
runtime, OS call or actual callee implementation executes in these checks.

Four source/native cases agree exactly:
- Begin-frame failure: one observation, no drawing.
- Active frame with mix 0: 30 observations.
- Mix 127, transition +0.25: 79 observations, including lower alpha clamp.
- Mix 255, transition -0.5: 79 observations.

Each case preserves stack balance, callee-save registers and the bool result.
The seven music columns are 15,0,1,17,3,4,5 for the specified fixture. Its
selected non-random character is 10; the other player takes the random path.
Changing only the final character-table entry makes the source/native traces
differ, providing an actual negative control for the full 64-byte table.
These finite cases are not universal semantic equivalence and cannot waive
any of the 163 different bytes. Eleven target-independent tests exercise the
boundary/padding contract and call-observer assertions.
